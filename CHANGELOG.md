# RNAmeta Desktop 1.0.1

- Aligned the 11 shared statistical and distribution modules with RNAmeta Online,
  including transcript boundaries, exon ranks, splice coordinates, heatmaps and
  Meta Plot mapping.
- Updated Genome Browser transcript mapping and sequence preparation.
- Enabled symmetric translation-boundary windows with the updated yeast sce_R64
  UTR annotation, while retaining the CDS-only reference compatibility path.
- Refreshed analysis cache identifiers and rebuilt the portable Windows package
  with its embedded analysis scripts, R runtime and RNAfold runtime.
